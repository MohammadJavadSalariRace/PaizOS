# 🍂 PaizOS (سیستم‌عامل پاییز)

[![Version](https://img.shields.io/badge/Version-4.0%20Cyber--Autumn-orange.svg)](https://github.com/MohammadJavad/PaizOS)

**PaizOS (پاییز)** یک هسته سیستم‌عامل سبک، امن، فوق‌العاده سریع و متن‌باز است که از صفر به زبان C و Assembly برای معماری x86 توسعه داده شده است. این پروژه با الهام از اصالت ایرانی و فصل پاییز، به عنوان یک پروژه پیشرفته متن‌باز و مدرن طراحی شده است.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

- 🛡️ **دژ امنیتی هسته (PaizOS Shield):** محافظت در برابر حملات Buffer Overflow با Stack Canary و ایزوله‌سازی صفحات حافظه هسته (KPTI Guard).
- ⚡ **تخصیص‌دهنده حافظه Slab Allocator:** مدیریت حافظه فوق‌سریع بدون اوورهدر جهت جلوگیری از تکه‌تکه شدن (Fragmentation) RAM.
- 🧠 **مدیریت حافظه مجازی (Paging):** صفحه‌بندی ۴ کیلوبایتی حافظه جهت ایجاد محیط امن و ایزوله برای پروسه‌ها.
- ⚡ **زمان‌بندی و چندوظیفه‌ای (Task Scheduler):** پشتیبانی از چندپروسه‌ای و تعویض بافتار (Context Switching) با الگوریتم Round-Robin.
- 🎨 **موتور گرافیکی ۳۲ بیتی VBE:** پشتیبانی از حالت گرافیکی رزولوشن ۱۰۲۴x۷۶۸ با قابلیت رندر افکت‌های شیشه‌ای (Glassmorphism).
- 📁 **سیستم فایل مجازی (VFS):** ساختار Ramdisk داخلی برای مدیریت، ساخت و خواندن فایل‌ها.
- 🤖 **هوک اختصاصی هوش مصنوعی:** ثبت وقفه اختصاصی `int 0x81` برای پردازش‌های سنگین و ارتباط با مدل‌های هوش مصنوعی.
- 🔄 **بازیابی خودکار از خطاهای بحرانی:** بازیابی و Snapshot هسته در کمتر از ۵ میلی‌ثانیه بدون ریستارت کامل سیستم.

## 📜 تاریخچه نسخه ها (Changelog)

### 🍂 نسخه ۴.۰ - Cyber-Autumn Edition (آخرین نسخه)
- پیاده‌سازی سیستم امنیتی **Stack Canary Guard** و **KPTI**.
- پیاده‌سازی تخصیص‌دهنده حافظه پرسرعت **Slab Allocator**.
- ارتقای درایور تصویر به **VBE 32-bit Glass Graphics Engine**.
- اضافه شدن هوک اختصاصی `int 0x81` برای پردازش‌های سنگین و AI.
- افزودن مکانیزم بازیابی خودکار از Kernel Panic.

### 🍃 نسخه ۳.۰ - Ultimate Kernel Edition
- پیاده‌سازی حافظه مجازی و **Paging** با صفحات ۴ کیلوبایتی.
- افزودن زمان‌بند پروسه‌ها (**Task Scheduler**) و چندوظیفه‌ای.
- پیاده‌سازی سیستم فایل مجازی (**VFS**) و **Ramdisk**.
- افزودن رابط فراخوان‌های سیستمی (**Syscalls**) با وقفه `int 0x80`.
- توسعه پوسته تعاملی PaizOS Shell v3.0 با دستورات `ls`, `ps`, `sysinfo`.

### 🌿 نسخه ۲.۰ - Interactive Edition
- راه اندازی جدول توصیف‌گر سراسری (**GDT**) و جدول وقفه‌ها (**IDT**).
- پیاده‌سازی درایور کیبورد **PS/2** و دریافت ورودی‌های کاربر.
- پیاده‌سازی درایور تایمر سیستم (**PIT**) و ساعت واقعی (**RTC**).
- ایجاد سیستم تخصیص حافظه هیپ اولیه (`kmalloc`).
- ساخت اولین پوسته تعاملی (Shell) خط فرمان.

### 🍁 نسخه ۱.۰ - Bare-Metal Boot
- پیاده‌سازی هدر **Multiboot** و راه‌انداز اولیه اسمبلی (`boot.asm`).
- سوئیچ موفق به حالت ۳۲ بیتی (Protected Mode).
- توسعه درایور متنی VGA در آدرس `0xB8000`.
- ساخت اسکریپت لینک‌کننده (`linker.ld`) و اتوماسیون کامپایل (`Makefile`).

```text
PaizOS/
